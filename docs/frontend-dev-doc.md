# 前端开发文档（V0.1）

## 1. 目标与定位

- 前端目标：构建一个“炫酷但可用”的 AI 工作流平台界面。
- 首屏目标：强化品牌感与科技感，同时提供明确转化入口（注册/登录/快速开始）。
- V1 核心：首页视觉 + 鉴权页 + 工作台入口骨架。

---

## 2. 技术选型

- 框架：React + TypeScript + Vite。
- UI：Ant Design（业务组件）+ TailwindCSS（视觉自由度）可并存。
- 动效：Framer Motion（主动效编排）+ CSS Keyframes（轻量循环动画）。
- 画布：React Flow（工作流编辑器阶段接入）。

---

## 3. 首页信息架构（Landing Page IA）

## 3.1 首屏布局
- 顶部导航：Logo、产品价值、文档、登录、注册。
- Hero 文案区：核心 Slogan + 副文案 + CTA。
- 视觉主舞台：供应商图标“旋转发散”动效区。
- 快速功能区：进入控制台、模板市场、在线 Demo、API 文档。
- 信任背书区：已支持模型/供应商、功能亮点、场景卡片。

## 3.2 必须有的入口按钮
- `注册`（Primary）。
- `登录`（Secondary）。
- `立即体验`（进入 Demo 工作流）。
- `查看文档`（对接开发者）。

---

## 4. 炫酷首页视觉方案（重点）

## 4.1 视觉主题建议
- 主色：深色背景 `#070B14`，高亮电蓝/霓虹青 `#4FD1FF`，辅助紫 `#8B7CFF`。
- 氛围：星云渐变 + 微粒子浮动 + 玻璃拟态卡片。
- 原则：炫酷优先，但保证按钮/文本对比度达到可读标准。

## 4.2 “供应商图标旋转发散”组件方案
- 中心锚点：平台 Logo 或 “Workflow Engine” 核心徽标。
- 环形轨道：2~3 层同心轨道，图标沿轨道自转+公转。
- 发散效果：hover 或定时触发时，图标沿法线方向轻微外扩并回弹。
- 深度层次：前景图标清晰、后景图标模糊缩放，形成 3D 视差错觉。
- 交互反馈：点击某图标弹出供应商能力卡片（模型、延迟、价格标签）。

## 4.3 建议的首批供应商图标池
- OpenAI

> 注意：商标使用需遵循各供应商品牌规范，建议在正式商用前补齐法务检查。

## 4.4 动效实现建议（性能优先）
- 动效分层：
  - 背景层：纯 CSS 动效（渐变流动、粒子）。
  - 图标层：Framer Motion 控制轨道旋转与 hover 发散。
  - 内容层：淡入+轻微上浮，避免重型位移动画。
- 性能约束：
  - 同屏动画元素控制在 40 个以内。
  - 尽量使用 `transform`、`opacity`，避免频繁触发布局重排。
  - 对低性能设备降级为静态环形排布。

## 5. 页面与路由规划（V1）

- `/`：炫酷首页（登录/注册/体验入口）。
- `/login`：登录页。
- `/register`：注册页。
- `/console`：控制台首页（鉴权后）。
- `/workflows`：工作流列表。
- `/workflows/:id/editor`：工作流编辑器（后续迭代重点）。

---

## 6. 鉴权前端需求

- 登录方式：邮箱+密码（V1），第三方登录（V2）。
- Token 策略：Access Token + Refresh Token。
- 前端存储：优先 HttpOnly Cookie（推荐）；如使用 localStorage 需严格 XSS 防护。
- 登录态守卫：路由守卫 + 401 自动刷新 + 失效回登录页。

---

## 7. 组件清单（优先级）

- `HeroSection`：文案 + CTA。
- `VendorOrbitalShowcase`：旋转发散供应商图标核心组件。
- `FeatureQuickActions`：基础功能入口按钮组。
- `AuthModal / AuthPage`：注册登录容器。
- `HeaderNav`：顶部导航与用户态切换。

---

## 8. 前端开发里程碑（2 周）

### Week 1
- 完成视觉规范（色板、字体、间距、动效节奏）。
- 完成首页静态结构与响应式布局。
- 完成 `VendorOrbitalShowcase` 第一版动效。

### Week 2
- 完成登录/注册页面与接口联调。
- 完成首页按钮入口跳转与鉴权态切换。
- 完成首屏性能优化与动效降级策略。

---

## 9. 验收标准（Frontend DoD）

- 首页具备明显“科技炫酷”视觉特征，且首屏可读性良好。
- 注册/登录路径完整可用。
- 供应商图标旋转发散组件可交互、不卡顿。
- 关键入口按钮可达并连通对应页面。
- 移动端与桌面端布局均可用。
